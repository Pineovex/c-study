# 音乐目录

把要放的歌直接丢在这个文件夹里就行，支持这些格式：

```
.mp3  .m4a  .ogg  .wav  .flac  .aac
```

文件名会变成页面上的歌名（下划线换成空格，扩展名去掉）。比如：

```
起风了.mp3        →  起风了
lofi_beats_01.mp3 →  lofi beats 01
```

加完之后**不需要改任何代码**：提交推送，GitHub Actions 会自动重新生成 `docs/data.js`，
右下角那个音符按钮里就会出现新歌，按文件名排序。

注意：

- 别放你没权利公开分发的歌（版权问题自己负责）。
- 文件别太大，Pages 单文件超 100 MB 会被拒绝，仓库整体也建议别超过 1 GB。
- 想按顺序排就把文件名前面加数字，比如 `01-xxx.mp3`、`02-yyy.mp3`。
